# COR3 Helper Unified v1.8.6-unified.1

**COR3 Helper Unified** brings Firefox MV3 compatibility and safe, fail-closed automation to the COR3 Helper ecosystem.

It unifies the active feature set of **SaltApocalypse** (`v1.8.5-salta.1`), the Firefox MV3 extension architecture of **3ncy** (`v1.6.1`), and loadout resolver techniques inspired by **Nightingale** (`af3c9dd`), building upon the original upstream extension by **Femtoce11**.

---

## What's New

### 🦊 Firefox MV3 Support
- Full Firefox MV3 compatibility utilizing `background.scripts` execution with clean dependencies (`console-logger.js`, `errors.js`, `background.js`).
- Graceful degradation for Chrome-only `chrome.sidePanel` APIs (no broken UI or popup errors).
- Clean Gecko ID: `cor3-helper-unified@lr7.local`.
- Scoped web-accessible resources restricted strictly to `cor3.gg` origins.

### 🛡️ Safe Job Eligibility Engine & Non-Destructive Dry Run
- Pure, fail-closed eligibility solver in `src/shared/job-eligibility.js`.
- **Dry Run Mode**: Opt-in toggle to test and inspect all job conditions without spending deposits or signing contracts.
- **Transit Path Defense Verification**: Automatically evaluates every intermediate server hop along network paths (e.g., blocking target servers behind higher-hack hops when underpowered).
- **Reserve Cash Protection**: Guards player-configured credit minimums so deposits never overdraft your balance.
- **Server Maintenance & Timeout Guards**: Fails closed if any server on the route is in maintenance or if a job expires in < 60 seconds.
- **Access Type Differentiation**: Correctly separates pre-sign Access Acquisitions from post-sign Access Grants.

### 🖥️ Multi-Combo Loadout Resolver & Purchase Suggestions
- Multi-combination software/hardware solver evaluates all owned CPU, GPU, RAM, and PSU combinations to maximize target function power (Hack, Decrypt, etc.).
- **Zero Fantasy Math**: Calculations adhere to runtime hardware specs and official game formulas.
- **PSU Power & Boot Constraints**: Enforces total system wattage constraints to prevent unbootable hardware setups.
- **Catalog Upgrade Recommendations**: When owned hardware falls short of job requirements, pinpoints the cheapest missing catalog hardware to purchase manually — without automatic spending.
- **No Unnecessary Hardware Swaps**: Detects identical hardware configurations before issuing change requests.

### ⚡ Preserved Upstream & Modern Salt Features
- Full support for Mailbox auto-claims (`mail.js`).
- Automated drone mission tracking (`drone.js`).
- Warehouse stash sorting (`stash-sort.js`).
- Mercenary insurance and cost threshold controls (`auto-send.js`).
- Safe DOM handling via `replaceChildren` and DOM text nodes across UI tables to comply with modern extension security guidelines.

## Downloads & Installation

### Firefox (Firefox 109+)
1. Download **`cor3-helper-unified-v1.8.6-firefox.zip`** and extract it to a directory.
2. In Firefox, navigate to `about:debugging#/runtime/this-firefox`.
3. Click **"Load Temporary Add-on..."** and select `manifest.json` from the extracted folder.
4. Navigate to [cor3.gg](https://cor3.gg) or [os.cor3.gg](https://os.cor3.gg) and open the extension popup.

### Chrome / Chromium (Chrome 120+)
1. Download **`cor3-helper-unified-v1.8.6-chrome.zip`** and extract it to a directory.
2. In Chrome, navigate to `chrome://extensions/` and enable **"Developer mode"** in the top right.
3. Click **"Load unpacked"** and select the extracted folder.
